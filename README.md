# Simplex: Easy to use CMS/LMS for productive developers and businesses

## About Simplex
Simplex is a Hybrid CMS (Content Management System)/ LMS (Learning Management System) for serving and managing content for both readers and Learning. It is packed with amazing features for readers and learners.
